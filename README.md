# ExamSphere — Smart Student Examination System

A customized student exam website built with HTML, CSS and JavaScript.

## Included
- Distinct purple/lavender responsive design
- Student details form and subject selection
- Instructions screen
- 10 MCQs for Computer Science, General Knowledge and English
- 10-minute timer, previous/next navigation and progress
- Auto-submit, score percentage and answer review
- Dark mode

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Publish on GitHub Pages
1. Create a GitHub repository, e.g. `examora-portal`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch, choose `main` and `/(root)`, then Save.
5. Wait for deployment. Your link will be `https://YOUR-USERNAME.github.io/examora-portal/`.

## Important
This is a front-end demonstration. It does not have secure authentication, a database, permanent result history, an admin backend or secure proctoring. Do not use it for high-stakes exams or sensitive student information. Add a secure backend and database before production use.
